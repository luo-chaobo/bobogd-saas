# 非标钣金云端小程序工单系统 V2

这是第二阶段工程，覆盖网页管理后台、微信小程序工程、后端接口、云端配置模板、数据库集合设计和岗位使用说明。

## 启动方式

推荐双击英文启动文件，避免 Windows 命令行中文编码导致闪退：

```text
start-system.cmd
```

启动窗口不要关闭。启动成功后访问：

```text
http://localhost:3000
```

电视大屏看板访问：

```text
http://localhost:3000/tv.html
```

大屏页面会自动刷新。工人通过手机端报工完成后，对应工序节点会显示完成时间和报工人。

大屏工单排序和颜色规则：

- 橙红色：已延期工单
- 浅红色：距离交期 48 小时内的加急工单
- 正常色：普通工单
- 所有工单都按交期从近到远排序
- 当前页展示不完时，每 2 分钟自动翻到下一页
- 派工页面可为每道工序设置目标完成时间，并显示到电视大屏
- 每个工单可以单独增减工序，新增工序可选：设计、激光、切管、折弯、压铆、攻丝、焊接、机加、打磨、喷塑、装配、质检

也可以使用本机可用 Node.js 启动：

```powershell
node server.js
```

当前 Codex 环境可使用自带 Node：

```powershell
C:\Users\luoch\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe server.js
```

启动后访问：

- 后台/手机端体验：http://localhost:3000

## 微信小程序工程

小程序工程目录：

```text
miniprogram
```

用微信开发者工具打开 `miniprogram` 目录。首次打开后需要：

1. 把 `miniprogram/project.config.json` 里的 `appid` 改成你的微信小程序 AppID。
2. 把 `miniprogram/utils/config.js` 里的 `apiBaseUrl` 改成正式 HTTPS 后端域名。
3. 在微信小程序后台配置 request 合法域名。
4. 如果使用微信云开发，把 `cloudEnvId` 改成云开发环境 ID。

开发阶段如果还没有正式域名，可以先用本地地址：

```js
apiBaseUrl: "http://localhost:3000"
```

真机预览时，手机需要能访问这个地址；正式发布必须使用 HTTPS 域名。

## 双模式扫码报工

系统同时支持两种扫码方式：

- 微信首页“扫一扫”：扫描微信官方小程序码，直接进入对应工序报工页。
- 波波工单内“扫码报工”：扫描普通二维码，在当前小程序内进入对应工序。

服务器启动时需要配置以下环境变量：

```text
PORT=3000
QR_BASE_URL=https://bobogd.wljixie.com
WX_APPID=微信小程序AppID
WX_APP_SECRET=微信小程序AppSecret
WX_CODE_ENV_VERSION=trial
```

测试体验版使用 `trial`，小程序正式发布后改成 `release` 并重启 PM2。`WX_APP_SECRET` 只能保存在服务器环境变量中，禁止写入小程序代码、公开文档或代码仓库。微信小程序码会缓存在 `data/weapp-code-cache`，无需每次打印都重新请求微信接口。

## 云端/微信小程序上线准备

当前版本是“云端结构原型”：后端、接口和移动端逻辑已经按云端方式设计，但运行在本地电脑上。正式上线需要准备：

- 微信小程序账号和 AppID
- 云服务账号
- 正式域名和 HTTPS
- 数据库、文件存储、备份策略
- 小程序隐私政策和用户协议
- 小程序体验版测试人员
- 正式发布审核资料
