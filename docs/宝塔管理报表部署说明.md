# 宝塔管理报表部署说明

本次新增后台管理分析 XLSX 导出、基础报表日期筛选、后台表格排序，并隐藏基础设置中的大屏看板设置。

## 需要上传

- `server.js`
- `lib/management-report-export.js`
- `public/app.js`
- `public/styles.css`
- `public/index.html`
- `package.json`
- `pnpm-lock.yaml`

## 部署步骤

1. 在宝塔备份上述线上文件，并备份 `app_state.main`。
2. 停止 Node 项目，按原目录上传文件。
3. 在项目目录执行 `pnpm install --prod`。若服务器使用 npm，可执行 `npm install --omit=dev`，以 `package.json` 为准安装 `exceljs`、`jszip` 和 `mysql2`。
4. 重启 Node 项目，确认日志中没有 ExcelJS 或 JSZip 加载错误。
5. 登录后台“基础报表”，选择日期并导出 XLSX；使用 Excel/WPS 检查六个工作表和四张可悬停的原生图表。
6. 检查生产总览、历史查询、质检详情、基础报表和操作日志的表头排序。
7. 进入基础设置，确认大屏设置已隐藏；再打开电视看板确认原配置继续生效。

本次不需要上传数据库文件、小程序、电视看板文件或 APK，不需要修改数据库结构。
