## SaaS 隔离改造的本轮代码范围

- 平台目录连接使用独立的 `SAAS_CATALOG_MYSQL_*` 配置；未来机械预置库由 `SAAS_TENANT_DATABASES_JSON` 配置，新租户由平台目录登记的预配元数据和服务端派生凭据路由。
- 每个租户不得共享业务库；路由缺失时 fail closed；拒绝 `bobogd`、`future_orders`、目录库及已配置的旧共享库。
- SaaS 状态固定只读写租户库自身的 `app_state.main`，不再以 `saas_tenants.state_key` 共用数据库；平台 API 在加载业务状态前处理。
- 新公司创建时由服务端预配独立空数据库（仅一个空的 `app_state` 表）和专属应用账号；不会自动覆盖或迁移旧业务数据。
- 租户 API 状态操作由 MySQL `GET_LOCK` 按租户跨进程串行化；文件访问、平台管理员密码重置、租户引导和外协伙伴库读写也使用相应租户锁。正式部署仍需验证 MySQL 命名锁、锁等待和中断恢复。
- 本地启动脚本使用分库账号和 DPAPI 保存的凭据；创建空白未来机械测试租户时才按一次性输入的管理员信息初始化空状态。
