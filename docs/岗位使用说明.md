# 各岗位使用说明

## 老板

1. 用老板账号登录。
2. 进入“手机端预览”或移动端看板。
3. 查看生产中工单、异常数量、延期风险。
4. 点开工单卡片，查看当前工序、完成比例和交期。
5. 看到异常后，可联系生产主管处理；必要时也可以在异常页面标记处理结果。

老板重点看三件事：哪些订单在做、哪些订单快延期、哪些工单有异常。

## 车间电视大屏

1. 在连接电视的电脑上打开浏览器。
2. 访问 `http://localhost:3000/tv.html`。
3. 设置浏览器全屏显示。
4. 大屏会自动刷新生产状态、延期工单、工序负荷和最新报工动态。
5. 工人通过手机端提交报工后，对应工序节点会显示该次完成时间和报工人。
6. 生产主管设置的目标完成时间会显示在每个工序节点下方。
7. 工单颜色规则：橙红色是延期工单，浅红色是 48 小时内加急工单，正常色是普通工单。
8. 工单按交期从近到远排序，当前页放不下时每 2 分钟自动向下轮播。

电视大屏重点展示：工单进度、工序节点、完成时间、延期预警和最新报工。

## 生产主管

1. 登录网页后台。
2. 在“客户资料”维护客户名称、联系人、电话、地址和备注。
3. 在“订单工单”中新建订单，填写客户、产品、图号、数量和交期。
4. 按本单实际情况勾选工序路线。可选工序包括：图纸设计、激光、折弯、压铆、打孔攻丝、焊接、打磨、喷塑、组装。
5. 进入“派工路线”，把每道工序分配给对应员工，并填写目标完成时间。
6. 每个工单的工序可以单独调整：需要追加工序时，在工单底部选择工序、负责人和目标完成时间后点击“新增工序”；未报工的工序可以删除。
7. 在“生产总览”查看所有工单进度。
8. 在“异常返工”处理工人提交的异常，可填写处理说明并标记已解决。
9. 每天查看“基础报表”，了解员工报工和产出，也可导出报工 CSV。

主管重点保证：工单建得准、工序派得清、异常处理及时。

## 办公室/跟单

1. 登录网页后台。
2. 在“客户资料”新增或核对客户信息。
3. 在“订单工单”录入客户订单。
4. 查看工单交期、当前工序和生产状态。
5. 接客户电话时，在“生产进度看板”确认订单进度。
6. 需要统计时，在“基础报表”导出报工 CSV 或完整数据。

跟单重点保证：订单信息准确、交期状态清楚、客户询问时有依据。

## 车间工人

1. 用自己的账号登录手机端。
2. 进入“我的任务”。
3. 找到自己要做的工序任务。
4. 开始加工时可以点“开始”，临时停工时可以点“暂停”。
5. 完成后填写：
   - 完成件数
   - 合格数量
   - 不良数量
   - 返工数量
   - 备注
6. 需要时可以选择或拍摄现场图片。
7. 没有异常时，异常类型和异常说明可以不填。
8. 有异常时，填写异常类型和说明，再提交报工。

工人重点保证：完成后及时报工，数量填写真实，有问题及时上报。

## 质检

1. 用质检账号登录手机端。
2. 查看分配给自己的质检任务。
3. 填写合格、不良、返工数量。
4. 发现质量问题时，提交异常说明。
5. 在异常页面查看待处理质量问题。

质检重点保证：质量问题能记录到具体工单和工序。

## 管理员

1. 登录网页后台。
2. 在“基础设置”查看员工账号、角色和标准工序。
3. 后续正式版中维护员工、角色、权限、工序、客户资料。
4. 协助主管检查账号是否能正常登录。

管理员重点保证：账号、权限、基础资料正确。
