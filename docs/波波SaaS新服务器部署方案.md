# 波波 SaaS 新服务器部署方案

更新日期：2026-10-31（Asia/Shanghai）

## 总体方案

新服务器部署统一的 SaaS 程序，未来机械和外协租户运行同一套应用代码，但各自使用独立业务数据库。旧服务器上的生产程序和数据在并行验收期间保持原样。

初期在新 ECS 上自建 MySQL，作为隔离试运行与首期部署数据库；后续可迁移到 RDS。SaaS 不直接连接旧生产库，未来机械生产备份快照只迁入新环境中独立的未来机械租户库。未来机械业务库、SaaS 平台目录库及外协租户库保持逻辑独立，未来机械主数据不与外协租户共库。初期自建 MySQL 与应用若同机部署，属于共享故障域，不具备 RDS 高可用能力，正式承载工厂关键生产前须评估独立数据库主机或迁移 RDS。

小程序只配置一个正式 API 域名，不在客户端对两套后端分流。当前 SaaS 小程序副本仍指向 `https://bobogd.wljixie.com`，正式 SaaS 域名需另行准备。SaaS 工作区有未提交修改，须先审阅差异、验收，再从确认的版本制作含文件清单和 SHA-256 的发布包；只读主程序目录保持不动。

## 采购与初始配置

| 资源 | 建议起步配置 | 用途 |
|---|---|---|
| SaaS 应用 ECS | 杭州地域，4 vCPU、8 GiB；ESSD 系统盘 40 GiB、PL0；公网按流量计费，初始峰值带宽 5 Mbps | SaaS 网页、API、小程序接口 |
| MySQL | 初期部署在新 ECS 的独立 MySQL 服务；建议与应用分盘/限制资源，禁止公网开放数据库端口 | SaaS 平台目录及租户业务库；按租户独立数据库和账号 |
| 附件存储 | 私有 OSS Bucket | 图纸、照片和附件；按租户授权访问 |
| 备份 | MySQL 自动定时备份，并将副本保存至独立 ECS 或私有 OSS；正式采用 RDS 后启用自动备份和时间点恢复 | 误操作、故障恢复及迁移回退 |

4 vCPU、8 GiB 和 5 Mbps 是起步询价/试运行建议，不是 50 家租户容量保证。容量取决于活跃用户、订单量、看板刷新频率、附件大小和并发；上线后按监控扩容。单台应用 ECS 是单点；需要应用层高可用时再增加第二台 ECS 和负载均衡。

应用和 MySQL 放在同地域/专有网络。MySQL 不开放公网 3306，仅允许应用主机及受限管理来源访问。服务器只开放 HTTPS 和受限来源管理端口。数据库凭据、生产文件、备份和密钥不得放入代码目录或发布包。

## 部署和切换顺序

1. **采购与入口准备**：创建新 ECS 和私有 OSS，规划 MySQL 备份副本位置；准备 SaaS 子域名（建议 `saas.wljixie.com`，需核实备案和证书），配置 DNS、HTTPS 和安全组。初期暂不购买 RDS。
2. **准备服务**：在新 ECS 部署独立 SaaS 目录、服务、端口和日志目录；生产密钥由受控密钥管理提供。平台目录使用独立库/账号；未来机械和每家外协公司分别使用独立业务库及最小权限账号。数据库预配账号只用于开户和授权，不用于日常业务查询。
3. **先做隔离验收**：使用测试数据创建测试租户，验证各租户账号只能访问自己的库；检查附件、搜索、导出、看板、套餐和外协权限。未来机械快照只进入隔离验收环境，不连接现网生产库。
4. **备份与恢复演练**：配置 MySQL 自动备份及异地副本，记录版本、字符集、库清单和恢复步骤；在隔离环境至少完成一次恢复演练，并核验记录与附件。演练不通过，不进入生产切换评估。
5. **迁移演练**：从经确认的未来机械生产备份快照导入独立的未来机械 SaaS 租户库，核对记录数量、关键业务数据、附件可读性、员工角色和审计数据；不得修改现网生产库。
6. **小程序体验版联调**：仅修改 SaaS 副本中的 API 地址为新 HTTPS 域名；在微信公众平台增加 request 合法域名；使用微信开发者工具体验版验证未来机械和外协账号登录、套餐菜单、报工、委派进度、图纸附件、看板及平台订单回传。当前正式版继续服务工厂。
7. **正式切换**：安排维护窗口，暂停旧系统写入并制作最终备份；将最终一致快照导入未来机械专属 SaaS 租户库，核对通过后启动新 SaaS。确认新 SaaS 是唯一写入入口，避免新旧系统同时接单造成数据分叉。
8. **观察和回退**：观察登录、API 错误、数据库连接、磁盘、备份、回调队列及小程序反馈。旧服务器、旧程序和旧数据不删除、不覆盖。回退前暂停写入并执行已演练的数据恢复/回迁步骤；不能只把小程序地址改回旧服务器，否则切换后的新工单和报工可能丢失。
9. **后续迁移 RDS**：当业务稳定、容量或高可用要求需要时，另行采购 RDS MySQL 并先做隔离迁移演练。正式切换需停写、最终备份/同步、记录和附件核对、单次切换及回退预案；禁止新旧库双写。RDS 迁移不是只改连接字符串。

## 微信小程序和回传清单

- SaaS 小程序发布候选为 `bobo-saas-integration-staging\app\miniprogram`；不修改 `bobo-platform-delivery-worktree` 源目录。
- 将候选小程序 API 地址改为 SaaS 子域名，电视看板地址也指向新服务。
- 微信后台添加新 request 合法域名；确认 HTTPS 证书、业务域名和隐私配置。
- 使用体验版分别验证未来机械主租户和外协租户：未来机械应有完整菜单，外协租户只显示套餐授权模块，“外协监管”显示为“委派任务”。
- 在隔离联调环境验证订单接入 HMAC、工序确认、进度/交付回调、重试及 `eventId` 幂等。此前记录中的回调健康状态曾为 `enabled: false`，不能据代码存在认定线上回传可用。
- 所有验收通过后再提交小程序审核和发布；正式版发布前保留当前线上版本作为切换前基线。

## 上线门槛与默认假设

上线前必须通过：主程序功能逐项对照、MySQL 跨租户读写拒绝、附件/搜索/导出权限、未来机械快照迁移核对、数据库和附件恢复演练、微信体验版端到端、小程序回传幂等、正式域名 HTTPS、回退演练。

默认按 50 家总租户规划（未来机械 1 家、外协最多 49 家），单一微信小程序 AppID 和单一 SaaS API 域名，初期单台应用 ECS、自建 MySQL。自建 MySQL 与应用同机时属于单点和共享故障域；不宣称具备 RDS 高可用能力。此方案不代表已经购买云资源、完成服务器部署、生产迁移、DNS 切换或小程序发布。
