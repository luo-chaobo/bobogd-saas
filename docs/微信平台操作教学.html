微信小程序平台操作教学

用于把“波波工单 / 非标钣金工单系统”配置到微信小程序后台，并完成体验版、审核、发布。

当前结论

你的服务器和网站已经跑起来后，微信平台主要还要完成这几件事：

配置服务器域名 添加开发者/体验成员 开发者工具上传代码 设置体验版 提交审核 审核通过后发布

注意：微信小程序正式版必须使用 HTTPS 合法域名。你现在应使用 https://bobogd.wljixie.com 作为小程序接口域名。

一、准备内容

你需要准备

  • 微信小程序账号管理员扫码登录权限。
  • 小程序 AppID。
  • 已经能正常打开的接口域名：https://bobogd.wljixie.com。
  • 微信开发者工具。
  • 本机项目目录：D:\codex内容\copy黑湖小工单\miniprogram。

发布前建议确认

  • https://bobogd.wljixie.com 可以打开登录页。
  • https://screen.wljixie.com/tv.html 可以打开大屏看板。
  • 宝塔中 PM2 项目 bobogd 是 online。
  • 宝塔 SSL 已部署，并且浏览器不再提示证书错误。

二、配置服务器域名

1

进入微信公众平台

打开 mp.weixin.qq.com，用小程序管理员微信扫码登录。

2

找到服务器域名

左侧菜单进入：管理 → 开发管理 → 开发设置 → 服务器域名，点击右侧的修改。

3

填写合法域名

配置项 填写内容 说明
request 合法域名 https://bobogd.wljixie.com 小程序登录、查询任务、提交报工都走这里。
uploadFile 合法域名 https://bobogd.wljixie.com 后续上传现场照片、异常图片使用。
downloadFile 合法域名 https://bobogd.wljixie.com 后续下载图片、附件、二维码时使用。
socket 合法域名 暂不填写 当前版本没有使用 WebSocket。
udp / tcp 合法域名 暂不填写 当前版本不需要。
4

保存配置

点击保存。保存后建议关闭并重新打开微信开发者工具，避免开发者工具仍使用旧域名缓存。

三、业务域名要不要填？

第一版小程序主要通过接口访问后台，不需要在小程序里嵌入网页，所以业务域名可以先不配置。

只有当你以后想在小程序里直接打开网页，例如用 web-view 嵌入 https://screen.wljixie.com/tv.html 或网页后台时，才需要配置业务域名。

如果将来要配置业务域名，微信会要求你把一个校验文件上传到网站根目录。到时候按微信页面提示下载校验文件，再放进服务器对应网站目录即可。

四、添加开发者和体验成员

1

开发者

进入：管理 → 成员管理 → 项目成员。把需要上传代码的人添加为开发者。如果只有你自己上传，可以先不加其他人。

2

体验成员

进入：管理 → 成员管理 → 体验成员。添加老板、主管、工人测试手机对应的微信号。

体验版只有体验成员能打开。正式发布以后，普通微信用户才能正常搜索或扫码进入。

五、微信开发者工具上传代码

1

打开项目

打开微信开发者工具，选择导入项目，项目目录选择：

D:\codex内容\copy黑湖小工单\miniprogram

AppID 填你微信公众平台里的小程序 AppID。

2

确认接口地址

当前小程序配置应指向：

https://bobogd.wljixie.com

如果以后换域名，需要同步修改小程序代码里的接口地址，再重新上传版本。

3

编译和预览

点击编译，确认页面能打开。再点击预览，用手机微信扫码测试。

建议先测试这些账号：

  • 老板：13800000001 / 123456
  • 生产主管：13800000002 / 123456
  • 工人：13800000004 / 123456
  • 质检：13800000006 / 123456
4

上传版本

测试无明显问题后，点击右上角上传。

版本号建议填：1.0.0。项目备注可填：第一版：工单、扫码报工、生产看板。

六、设置体验版和提交审核

1

设置体验版

回到微信公众平台，进入：管理 → 版本管理。在开发版本里找到刚上传的版本，点击选为体验版。

2

体验版测试

让体验成员扫码打开体验版，完整跑一遍：

  • 登录是否正常。
  • 工人是否能看到自己的任务。
  • 扫码进入对应工序是否正常。
  • 提交报工后，后台和大屏看板是否同步变化。
  • 异常上报是否正常。
3

提交审核

体验版确认没问题后，在版本管理中点击提交审核。

类目建议选择和企业生产管理、效率工具、企业服务相关的类目。按平台实际可选类目为准。

4

审核通过后发布

微信审核通过后，版本管理页面会出现发布按钮。点击发布后，正式用户才可以使用正式版。

七、小程序备案提醒

如果微信平台提示需要做小程序备案，需要先完成备案后才能正式发布或持续提供服务。

你现在域名页面曾显示过“未备案”，这通常是网站域名 ICP 备案状态。微信小程序本身也可能有单独备案流程。两者不是同一个页面，但上线长期使用都建议补齐。

备案入口通常在微信公众平台左侧或顶部提示中，也可能在设置 / 基本设置 / 小程序备案相关页面里。按页面要求填写主体信息、负责人信息、服务内容并提交审核。

八、正式上线前检查清单

  • 浏览器打开 https://bobogd.wljixie.com 正常。
  • 浏览器打开 https://screen.wljixie.com/tv.html 正常。
  • 微信平台服务器域名已保存：request、uploadFile、downloadFile 都是 https://bobogd.wljixie.com。
  • 微信开发者工具能编译、预览、上传。
  • 体验成员手机能打开体验版。
  • 扫码报工、提交报工、异常上报、后台看板、大屏看板都测试通过。
  • 宝塔 PM2 里的 bobogd 项目在线。
  • 服务器重启后，PM2 能自动恢复项目。

九、常见错误处理

问题 原因 处理办法
request:fail url not in domain list 微信平台服务器域名没填，或开发者工具缓存旧配置。 确认 request 合法域名已保存为 https://bobogd.wljixie.com，然后重启微信开发者工具。
上传图片失败 uploadFile 合法域名未配置。 在服务器域名中添加 uploadFile 合法域名。
浏览器能打开，小程序打不开 通常是 HTTPS、合法域名、证书链或小程序备案问题。 先确认 HTTPS 证书有效，再检查微信平台服务器域名是否保存。
开发者工具本地能跑，手机体验版不能跑 开发者工具可能勾选了“不校验合法域名”。 正式测试时取消该勾选，按真实微信环境测试。
扫码报工二维码打不开 二维码地址、接口域名或服务器服务异常。 确认后台能打开，PM2 在线，并重新打印最新二维码。

十、以后更新小程序怎么做

  1. 先在本地修改和测试代码。
  2. 如果改了小程序端，打开微信开发者工具重新上传版本，例如 1.0.1。
  3. 在微信公众平台把新版本设置为体验版，先让内部人员测试。
  4. 测试通过后提交审核。
  5. 审核通过后点击发布。

服务器端代码如果更新，需要同步上传到宝塔服务器，并重启 PM2 项目。小程序端代码如果更新，需要通过微信开发者工具重新上传并走审核发布流程。
