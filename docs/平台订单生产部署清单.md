# 平台订单来源功能生产部署清单

状态：本地开发中，生产未部署、未验证。以下清单是本次本地验收得到的候选文件，真实上线前仍需用户逐项确认。

## 部署前

- 核验生产代码版本与本地功能分支的共同基线。
- 停止生产写入，备份生产代码、MySQL `app_state.main` 和上传目录。
- 保存当前 PM2/宝塔启动配置和环境变量名称，不在文档记录密钥值。
- 平台外部建单仅支持单 Node 进程：PM2 配置 `instances=1`，禁用 cluster 模式；MySQL 的整行 JSON 状态不支持多实例并发写入。
- 确认网站端人工同步开关仍为关闭状态。

## 验收

本地当前证据：波波串行全量测试 `75/75` 通过；网站核心人工同步回归 `16/16` 通过，网站全量 `90/91`，唯一失败为既有未跟踪的 `miniprogram/pages/home/index.js` 触发 stale JavaScript shadow 检查，与本次改动无关。生产验收尚未开始。

- 选定少量平台订单人工同步，验证幂等、来源、统计和客户公开进度。
- 核对全部、工厂和平台三组统计的合计关系。

## 回退

- 关闭网站端平台同步。
- 停止波波写入并恢复部署前代码。
- 仅在数据异常时恢复部署前 `app_state.main`；恢复前再次备份当前状态。
- 恢复后回归人工订单、车间报工和看板。

## 禁止部署

- 本地 `data/db.json`、模拟客户和模拟订单。
- 测试密钥、隧道脚本、临时日志和测试附件。
- `tests/`、本地缓存和开发工具输出。
