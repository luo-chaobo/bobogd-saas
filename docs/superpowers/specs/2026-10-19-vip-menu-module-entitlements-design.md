# VIP 主菜单模块与租户功能边界设计

日期：2026-10-19（Asia/Shanghai）

## 目标

在本地 `bobo-saas-commercial` 副本中，将每个主菜单稳定映射为可由 VIP 套餐配置的功能模块；保持宁波未来机械主租户全功能，并按委派关系区别外协双方在“外协监管”模块中的操作。不得改动只读功能基线 `bobo-platform-delivery-worktree`、其小程序源文件、业务数据、生产数据库或线上服务。

## 当前实现与问题

- `lib/saas-features.js` 已定义 11 个模块，并将业务 API 路径映射到模块。
- `public/app.js` 根据 `/api/me` 返回的模块标识筛选主导航；外协监管另以模块标识显示。
- 平台后台已有套餐 CRUD、模块目录 API、租户单户覆盖 API 和数据库授权表。
- `future-machinery` 租户在服务端被固定授予完整模块集合；普通租户按套餐和覆盖计算模块。
- 菜单、模块目录、API 路由规则目前分散维护，容易出现某个菜单或 API 漏配。附件中的套餐页显示模块列表为空并出现“平台接口不存在”；当前源码存在对应套餐/模块目录路由，具体失败请求需要在本地运行流程复现后确认，不能先假定根因。

## 模块目录

沿用既有稳定键，避免套餐记录失配：

| 模块键 | 主菜单名称 | 说明 |
| --- | --- | --- |
| `dashboard` | 生产总览 | 含生产总览和生产看板 |
| `customers` | 客户资料 | 客户信息管理 |
| `orders` | 订单工单 | 订单、工单、图纸及交付相关能力 |
| `dispatch` | 派工路线 | 派工、路线和报工 |
| `quality` | 质检详情 | 质检与异常处理 |
| `customerFeedback` | 客户反馈 | 保留现有岗位权限限制 |
| `history` | 历史查询 | 历史业务查询 |
| `reports` | 基础报表 | 统计和导出 |
| `settings` | 基础设置 | 员工、工序及基础配置 |
| `outsourcing` | 外协监管 | 主租户外协管理与外协租户任务处理，按租户身份及关系授权展示不同操作 |
| `auditLogs` | 操作日志 | 保留现有岗位权限限制 |

模块键是套餐持久化契约，变更键需单独迁移；菜单名称及路由可以演进，但不能静默改变现存套餐含义。

## 权限与界面行为

- 以单一模块目录作为后台套餐勾选、租户导航和服务端 API 模块路由映射的来源，防止键名/名称漂移。
- 实际访问须同时满足：租户有效模块、员工岗位/动作权限，以及对应外协关系授权。菜单隐藏只改善界面，不构成访问控制。
- 宁波未来机械主租户始终获得全部模块；套餐和单户覆盖都不能关闭主租户模块。
- 对其他已有租户保留当前兼容全功能状态，除非平台管理员主动调整套餐/单户覆盖；新增租户仍需选择有效套餐。
- “外协监管”共用模块入口，但按访问者身份裁剪功能：
  - 未来机械主租户可建立/撤销委派关系、发出外协任务、监管自身委派的任务和进度。
  - 外协租户只查看和处理委派给本租户的任务；接收、进度、异常、附件、质检和交付操作继续受该委派关系的逐项授权控制。
  - 外协租户不能创建上游委派关系，不能读取其他租户或主租户完整监管清单。
- 原有角色权限（例如客户反馈、审计日志）继续独立限制功能，套餐开放不绕过角色权限。

## 组件与数据流

1. 模块目录描述稳定键、显示名称、导航入口及服务端 API 前缀映射。
2. 平台 API 返回该目录；套餐编辑器使用其生成勾选项并存储模块键。
3. `/api/me` 提供当前租户的有效模块集合；Web 主菜单按模块及角色权限渲染。
4. 服务端在业务 API 调用前解析模块归属，未授权模块返回 403；无法归属的业务 API 需纳入映射或明确登记为公共/认证基础接口，不能因未映射而默认开放。
5. 外协 API 在模块检查后继续执行租户隔离、委派关系范围和关系权限校验。

## 套餐页错误诊断

- 复现平台登录后加载套餐页，分别记录模块目录、套餐列表请求的 HTTP 状态、请求路径及响应错误，不记录令牌或凭据。
- 若本地运行的服务返回未知平台接口，确认浏览器静态资源、启动脚本工作目录和 Node 服务实际读取的是同一个 SaaS 副本，再修复对应断点。
- 若接口正常而列表为空，检查初始化目录/套餐表流程和前端空状态；保持既有租户数据，不以重建表或清库作为修复方法。

## 验收

- 套餐页能显示完整模块目录；套餐创建/编辑后精确保存并回读所选模块。
- 租户套餐及单户覆盖能影响菜单和 API；未授权 API 返回 403。
- 未来机械始终显示并能访问全部模块，套餐变更不能削减它的现有业务功能。
- 外协监管主租户能管理并监管委派；外协租户只处理发给自己的任务且遵循关系权限，跨租户访问被拒绝。
- 遗留已有租户默认兼容全功能；角色权限继续生效。
- 所有开发、文档和检查仅针对 SaaS 副本；检查不会连接生产 MySQL、发送外部消息、部署服务或更改只读基线。
- 采用自动化单元/API 测试、语法检查和 `git diff --check`（SaaS 副本无 Git 元数据时以文件检查替代）。本地测试不代表生产部署或生产数据已验收。

## 明确不在本次范围

- 计费支付、购买流程、套餐价格目录、自动续费。
- 线上发布、生产数据库迁移或权限变更、微信小程序发布。
- 改动未来机械业务表结构、迁移业务数据或复制源目录未提交改动。
- 支持外协租户继续向下游转委派；目前只实现主租户到外协租户的监管边界。
